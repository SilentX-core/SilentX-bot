# COSMIC CONTROL CENTER - FRONTEND (GITHUB PAGES)

## Hướng dẫn đưa lên GitHub Pages trong 3 phút:
1. Tạo một repository mới trên GitHub (ví dụ: `my-control-center`).
2. Tải toàn bộ các file trong thư mục này lên repository (`index.html`, `login.html`, `style.css`, `app.js`, `config.js`).
3. Mở file `config.js`, đổi `YOUR-HOSTING-PANEL-DOMAIN.com` thành địa chỉ domain hoặc IP backend của Hosting Panel bạn đang dùng.
4. Vào **Settings** của repository -> Chọn mục **Pages** -> Tại nhánh chọn `main` / `root` -> Bấm **Save**.
5. Đợi 30 giây là trang web sẽ online tại đường dẫn: `https://<ten-user>.github.io/<ten-repo>/`.
